# Authentication

## Overview

This section demonstrates practical implementation and administration of authentication methods and multifactor authentication (MFA) within Microsoft Entra ID.

The exercises use a fictional organisation, **Alenmac Consulting**, to demonstrate authentication scenarios relevant to real-world enterprise environments.

## Key Areas

- Microsoft Entra authentication methods
- Microsoft Authenticator registration and configuration
- Multifactor authentication (MFA)
- Number matching and authentication security
- Conditional Access policies requiring MFA
- Authentication testing and troubleshooting
