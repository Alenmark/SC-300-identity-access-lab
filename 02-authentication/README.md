# Authentication Management

## Overview

This section explores authentication methods and security controls used to verify user identities within Microsoft Entra ID.

## Areas Covered

- Multifactor Authentication (MFA)
- Authentication methods policies
- Passwordless authentication
- Self-Service Password Reset (SSPR)
- Password protection
- Authentication strengths

## Practical Objective

Demonstrate the ability to configure and manage secure authentication methods that protect organisational identities and resources.
