# Access Management

## Overview

This section focuses on controlling access to organisational resources through identity-based security policies and administrative permissions.

## Areas Covered

- Conditional Access policies
- Role-Based Access Control (RBAC)
- Privileged Identity Management (PIM)
- Administrative role management
- Named locations
- Risk-based access policies

## Practical Objective

Demonstrate the ability to implement access controls, enforce security requirements and manage privileged access using Microsoft Entra ID.
