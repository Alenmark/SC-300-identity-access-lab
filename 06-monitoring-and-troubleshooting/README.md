# Monitoring and Troubleshooting

## Overview

This section focuses on monitoring identity activity, investigating security events and troubleshooting authentication and access-related issues.

## Areas Covered

- Sign-in logs
- Audit logs
- Provisioning logs
- Risky users and sign-ins
- Authentication troubleshooting
- Microsoft Entra monitoring and reporting

## Practical Objective

Demonstrate the ability to investigate identity-related events, identify configuration issues and troubleshoot authentication and access problems.
