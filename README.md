## Project Overview

This repository documents my hands-on journey implementing and administering Microsoft Entra ID in a practical lab environment.

The objective is to develop and demonstrate practical skills in identity and access management, using real-world business scenarios based on the responsibilities of an Identity and Access Administrator.

Rather than focusing solely on theoretical knowledge, this portfolio emphasises practical configuration, implementation, testing, troubleshooting and technical documentation.

## Project Objectives

The key objectives of this project are to:

- Configure and manage identities within Microsoft Entra ID.
- Implement authentication and access management controls.
- Design and configure Conditional Access policies.
- Manage privileged identities and administrative roles.
- Configure and manage application identities.
- Implement identity governance and lifecycle management.
- Monitor identity activity and troubleshoot authentication issues.

## Lab Scope

The project is organised around the four main SC-300 skill areas.

### 01 – Implement and Manage User Identities

- User lifecycle management
- Group management
- Administrative roles
- Device identities
- External identities

### 02 – Implement Authentication and Access Management

- Multifactor Authentication (MFA)
- Authentication methods
- Passwordless authentication
- Self-Service Password Reset (SSPR)
- Conditional Access
- Role-Based Access Control (RBAC)

### 03 – Plan and Implement Workload Identities

- Application registrations
- Enterprise applications
- Service principals
- Managed identities
- Application permissions

### 04 – Plan and Implement Identity Governance

- Privileged Identity Management (PIM)
- Access reviews
- Entitlement management
- Lifecycle workflows
- Access governance

## Practical Learning Philosophy

The labs are designed around realistic enterprise identity management scenarios.

Each exercise aims to demonstrate not only how a particular Microsoft Entra feature works, but also why it is important, how it should be configured, and how its effectiveness can be validated.
