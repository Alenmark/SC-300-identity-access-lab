# Lab Screenshots and Evidence

## Overview

This directory contains screenshots captured during the implementation and testing of the Microsoft Entra ID labs.

## Evidence Categories

- Tenant configuration
- User and group management
- Authentication configuration
- Conditional Access policies
- Administrative role assignments
- Application configuration
- Identity governance
- Testing and validation results

## Documentation Guidelines

Screenshots will be organised by lab reference and will provide visual evidence of configurations and successful test outcomes.

Sensitive information, credentials and tenant identifiers will be removed or redacted before publication.
