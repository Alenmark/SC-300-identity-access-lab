# Lab Environment Setup

## Overview

This section documents the Microsoft Entra ID lab environment used throughout the SC-300 Identity and Access Administration portfolio.

The environment will simulate a fictional organisation, Alenmac Consulting, to provide a realistic setting for implementing and testing identity and access management configurations.

## Objectives

- Establish a clean Microsoft Entra ID tenant environment.
- Review tenant configuration and licensing.
- Configure administrative accounts.
- Establish test users and security groups.
- Document the lab architecture.
- Establish security and testing guidelines.

## Environment Components

| Component | Description |
|---|---|
| Microsoft Entra ID | Primary identity platform |
| Alenmac Consulting | Fictional organisation |
| GitHub | Lab documentation and version control |
| Microsoft Graph PowerShell | Identity administration and automation |
