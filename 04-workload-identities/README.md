# Workload Identities

## Overview

This section covers the management of non-human identities used by applications, services and automated workloads to access organisational resources.

## Areas Covered

- Application registrations
- Enterprise applications
- Service principals
- Managed identities
- Application permissions
- Certificates and client secrets

## Practical Objective

Demonstrate the ability to register applications, configure workload identities and manage application authentication and permissions.
